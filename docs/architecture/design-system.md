# Design System

Folioone's approved direction (November 2026) is a calm, neutral "browser chrome" workspace: a soft grey frame (`--sidebar`) holds a lighter canvas panel (`--background`) with large rounded corners, white cards with hairline borders and 20px radii, the system sans face throughout (semibold, tightly tracked display headings via the `font-display` utility), small letter-spaced uppercase labels (`eyebrow` utility), a black pill for primary actions, grey pills for secondary actions, and green (`--success`) reserved for status. The sidebar stays; its active link is a curved tab (`.nav-tab` in `globals.css`) that takes the canvas colour and grows concave flares at its right edge so it flows into the canvas panel, like an active browser tab flows into its toolbar. The canvas panel is its own scroll container from `md` up. Article reading surfaces keep the serif editorial face, and the public website keeps its own theme palettes. Avoid purple gradients, neon and excessive glass.

Tailwind CSS 4 and shadcn/ui (New York conventions) are configured as the sole UI foundation. Design tokens live in `src/styles/globals.css`; shared primitives live in `src/components/ui`. Components currently cover buttons, input, textarea, select, dialog, dropdown menu, tabs (pill segmented control), badge, avatar, and tooltip; `BrandMark` (`src/components/brand-mark.tsx`) is the shared wordmark. Sidebar and workspace navigation primitives are composed in `src/components/workspace/workspace-shell.tsx`.

Semantic danger tokens (`--danger`, `--danger-soft`, with `destructive` and `destructive-outline` button variants) are reserved for errors and destructive actions. Accessible primitives added for the Persona screens: `Switch` (native checkbox with `role="switch"`), `LiveRegions`/`useAnnouncer` for screen-reader announcements, and `ConfirmDialog` built on the shared Dialog.

Use semantic HTML, visible keyboard focus, accessible names, and responsive behavior. Prefer restrained radii and color usage. Expand tokens and variants rather than introducing another UI framework.
